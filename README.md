# 💧 Water Reminder App

A simple Python script that sends desktop notifications to remind you to drink water and take a short break. Staying hydrated is important for your health and productivity!

## 🚀 Features

- Sends a notification with a message to drink water.
- Customizable reminder interval (in minutes).
- Lightweight and easy to use.

## 📦 Requirements

- Python 3.x
- [`plyer`](https://pypi.org/project/plyer/) — For cross-platform notifications.
